# Using aria-labelledby in HTML

Proyecto demostrativo centrado en accesibilidad web (ARIA) utilizando **HTML5**. Muestra el uso práctico del atributo `aria-labelledby` para vincular múltiples elementos del documento como etiquetas descriptivas de un control de interfaz (en este caso, un deslizador de volumen).

---

## 🚀 Características

- **Accesibilidad Avanzada:** Implementación de `aria-labelledby` para asociar múltiples IDs de texto a un solo campo de entrada.
- **Controles Interactivos:** Ejemplo de interfaz para un reproductor de audio con botones de reproducción, silencio y barra de desplazamiento de volumen (`input range`).
- **Código Semántico:** Estructura limpia y fácil de entender para fines educativos.
